# LLMs Txt App

Exposes a `/llms.txt` route that serves custom content from the app's settings.

To be used for LLM discovery and AI agent access.

## Installation

1. On your account, run:
`vtex install muralsyourway.llms-txt-app@1.x`.
2. After that, go to `https://{{account}}.myvtex.com/admin/apps` and search for the app "LLMs Txt App".
3. Click on **"Settings"** and set the text content to be returned on the `/llms.txt` route.
4. **Save it.**
5. Check if working on `https://{{account}}.myvtex.com/llms.txt`.
